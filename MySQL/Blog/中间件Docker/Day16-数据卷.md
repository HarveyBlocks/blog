# 数据卷volume

## 需求来源

我们说,容器中打包了一个模拟的操作系统环境, 

但是, 里面只有最简化的内容, 

例如大部分的容器中是没有`vi`命令的,

因为与容器的允许没有关系

容器不需要这些没必要的资源

## 定义

>   数据卷是一个虚拟目录. 是**容器内目录**与**宿主机**(容器所在的机器,就是Linux机器)**目录**之间映射的叫桥梁

### 挂载数据卷

-   卷一创建,宿主机目录马上自动挂载(文件名是自动创建的一长串十六进制码,看不懂qwq),叫做**"匿名卷"**

-   在执行`docker run`命令时, 使用`-v 数据卷名(唯一):容器内目录`可以**完成数据卷挂载**
    -    数据卷名将作为`/var/lib/docker/volumns/`下的宿主机目录名
-   当**创建容器时,** 如果**挂载了数据卷且数据卷不存在**, 会**自动创建数据卷**
-   容器创建之后就没办法再完成挂载了
    -   所以`docker volume create`的存在意义呢?

### 查看容器有关的数据卷

```bash
docker inspect 容器名
```

### 宿主机的目录和数据目录的挂载

`/var/lib/docker/volumns/目录`,不要!我要自己决定!

-   在执行`docker run`命令时, 使用`-v 本地路径:容器内目录`可以**完成数据卷挂载**
    -   路径必须以**`./`**或**`/`**开头,以示为本地目录
    -   否则,认为是`/var/lib/docker/volumns/`下的目录
