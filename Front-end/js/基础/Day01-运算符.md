# 运算符

## 特殊运算

### `**`指数运算

>   Exponentiation ([ES2016](https://www.w3ccoo.com/js/js_es6.html)) 



```js
console.log(3 ** 2);
```

### `+`字符串连接



```js
console.log('A' + 'B');
console.log('A' + 5);
```

### `==`和`===`

-   `==` 值相等, 并且进行自动的类型转换

    ```js
    let x = 5;
    console.log(x == '5'); // true
    ```

-   `===` 值相等并且类型相等

    ```js
    let x = 5;
    console.log(x === '5'); // false
    ```



### 比较运算

-   如果将字符串与数字进行比较
    1.   把**字符串转换为数值**
    2.   *空字符串**将被转换为 **0
    3.   非数值字符串**将被转换为始终为**NaN**, 也就是**结果总是为false**
-   字符串和字符串比较
    -   从前往后, **逐个字符比较**, 出现不一样的就返回结果

### 拓展运算符

>   `...`

将数据集合中的元素展开, 放入另一个集合

数组展开

```javascript
// 复制数组（浅拷贝）
const arr1 = [1, 2, 3];
const arr2 = [...arr1]; // arr2: [1, 2, 3]

// 合并数组
const arr3 = [4, 5];
const merged = [...arr1, ...arr3]; // merged: [1, 2, 3, 4, 5]

// 作为函数参数（展开数组元素为独立参数）
const numbers = [10, 20, 30];
Math.max(...numbers); // 等价于 Math.max(10, 20, 30)，结果为 30
```

字符串

```js
const str = "hello";
const chars = [...str]; // chars: ['h', 'e', 'l', 'l', 'o']
```

对象(合并对象)

```js
// 复制对象（浅拷贝）
const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1 }; // obj2: { a: 1, b: 2 }

// 合并对象（后面对象属性会覆盖前面的）
const obj3 = { b: 3, c: 4 };
const mergedObj = { ...obj1, ...obj3 }; // mergedObj: { a: 1, b: 3, c: 4 }
```
