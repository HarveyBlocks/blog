# 列表



| short | for all                | description    |
| ----- | ---------------------- | -------------- |
| li    | list item              | 列表项目       |
| ul    | unordered lists        | 无序列表       |
| ol    | ordered lists          | 有序列表       |
| dl    | definition lists       | 自定义列表     |
| dt    | definition term        | 自定义列表组   |
| dd    | definition description | 自定义列表描述 |
| nl    | navigation lists       | 导航列表       |



## 无序列表示例

```html
<ul>
    <li>Coffee</li>
    <li>Milk</li>
</ul>
```

<ul>
    <li>Coffee</li>
    <li>Milk</li>
</ul>

## 有序列表示例

```html
<ol>
    <li>Coffee</li>
    <li>Milk</li>
</ol>
```

<ol>
    <li>Coffee</li>
    <li>Milk</li>
</ol>



## 自定义列表示例

```html
<dl>
    <dt>Coffee</dt>
    <dd>one Coffee</dd>
    <dd>two Coffee</dd>
    <dt>Milk</dt>
    <dd>one Milk</dd>
    <dd>two Milk</dd>
</dl>
```

<dl>
    <dt>Coffee</dt>
    <dd>one Coffee</dd>
    <dd>two Coffee</dd>
    <dt>Milk</dt>
    <dd>one Milk</dd>
    <dd>two Milk</dd>
</dl>

## 列表项

列表项可以使用较为复杂的内容, 比如段落, 图片, 列表

```html
<ol>
    <li>Americano
        <ul>
            <li>Coffee</li>
            <li>Water</li>
        </ul>
    </li>
    <li>Latte
        <ul>
            <li>Coffee</li>
            <li>Milk</li>
        </ul>
    </li>
</ol>
```
