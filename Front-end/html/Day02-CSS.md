# CSS

## 样式

| KEY              | VALUE                | DESCRIPTION  |
| ---------------- | -------------------- | ------------ |
| background-color | yellow/red/green/... | 元素背景颜色 |
| font-family      | verdana/arial...     | 字体         |
| color            |                      | 元素颜色     |
| font-size        | 20px                 | 字体大小     |





| KEY        | VALUE     | DESCRIPTION |
| ---------- | --------- | ----------- |
| text-align | center... | 居中对齐    |
|            |           |             |
|            |           |             |
|            |           |             |

## 使用

1.   内联样式

     style属性

2.   外部引用

     css文件+head标签下的meta标签引用stylesheet

     id+CSS描述

3.   内部样式表

     head标签下的style标签

## 定义标签样式缺省值

```css
body {background-color:yellow;}
p {color:blue;}
```

## 多种样式优先级

（内联样式）Inline style > （内部样式）Internal style sheet >（外部样式）External style sheet > 浏览器默认样式
