# 空间改变下的质点位移问题

## 原始问题

BV1923rzHEsK

## 抽象假设

-   $v$ 或 $v(t)$  : 质点在静止不变的空间下移动的速度随时间的变化, 其中 $t \ge 0$,且  $v(t) > 0$​ .

    如果质点的速度随时间变化, 过一会儿就将速度降为原来的一半, 将不能够到达终点

-   $X$ 或 $X(t)$ :  质点的位移随时间的变化, 其中 $t \ge 0$, 且 $X(0) = 0$.

-   $S$ 或 $S(t)$ : 终点到起点的距离随时间的变化, 其中 $t \ge 0$, $S(t)>0$ 在任意 $t \ge 0$ 下成立.

-   $S_0$: 在 $t=0$ 时, $S(t)$的值.

### 解决方案

$$
\frac{dX}{dt}=v +\frac{X}{S}\times \frac{dS}{dt}\\
已知 v(t) 且v(t)>0 对任意 t \ge 0 恒成立, \frac{dS}{dt}, S > 0 对于任意 t \ge 0 恒成立,\\
X(0)=0, S(0)=S_{0} > 0 ,v(0)=v_0 > 0\\
求X.当X(t_{0})=S(t_{0})时, 求t_{0} \\
解: 
\frac{dX}{dt}= v+\frac{X}{S}\times \frac{dS}{dt}\\
\frac{dX}{dt}- \frac{1}{S} \times  \frac{dS}{dt}\times X = v \\
令 P(t) = - \frac{1}{S} \times  \frac{dS}{dt} = - \frac{d(ln\left| S \right|)}{dt}, Q(t) = v\\
则 \frac{dX}{dt} + P(t) \times X = Q(t) , 是为一阶非齐次线性微分方程\\
其中, \int P(t)  dt = \int - \frac{d(ln\left| S \right|)}{dt} dt \\
即  \int P(t)  dt = -\int d(ln\left| S \right|) \\
解得 \int P(t)  dt = -ln\left| S \right| \\
又由于一阶非齐次线性微分方程的通解得: X = e^{-\int P(t)  dt} \left( \int e^{\int P(t)  dt} Q(t)  dt + C \right) \\
将 \int P(t)  dt = -ln\left| S \right| 代入得\\
X = e^{ln \left| S \right| } \left( \int e^{-ln \left| S \right| } Q(t)  dt + C \right) \\
X = |S| \left(   \int \frac{v }{|S|} dt + C \right) \\
X(t) = |S(t)| \left( \int_{0}^{t} \frac{ v(\tau) }{|S(\tau)|}d\tau + C \right) \\
t = 0 带入得\\
0 = |S_{0}| (\int_{0}^{0} \frac{v(\tau)}{|S(\tau)|} d \tau+C)\\
又S_{0} \not= 0 \\
所以 C = 0 \\
所以 X(t) = |S(t)| \int_{0}^{t} \frac{v(\tau)}{|S(\tau)|} d \tau  \\
由于 S(t)>0 对任意t \ge 0 恒成立\\
所以 X(t) = S(t)  \int_{0}^{t} \frac{v(\tau)}{S(\tau)} d \tau \\
当 X(t_{0})=S(t_{0})时 \\
\int_{0}^{t_0} \frac{v(\tau)}{S(\tau)} d \tau = 1\\
\int_{0}^{t_0} \frac{v(\tau)}{S(\tau)} d\tau = 1 \\
可带入 S(t) = S_0 + v_s \times t,v_s 为常数,v(t) = v_0, 得 t_0 = \frac{S_0}{v_s} (e^{\frac{v_s}{v_0}}-1) \\
接下来用牛顿迭代法求解有关t的方程 \int_{0}^{t} \frac{v(\tau)}{S(\tau)} d\tau = 1 在 t \ge 0 上的近似解: \\
令 F(t) = \int_0^t \frac{v(\tau)}{S(\tau)} d\tau - 1\\
则 F'(t) = \frac{dF}{dt} = \frac{v(t)}{S(t)} \\
由牛顿迭代法公式: t_{n+1} = t_n -  \frac{F(t_n)}{F'(t_n)} \\
则 t_{n+1} = t_n - S(t_n)(\int_0^{t_n}\frac{v(\tau)}{S(\tau)}d \tau -\frac{1}{v(t_n)})\\
其中, \int_0^{t_n}\frac{v(\tau)}{S(\tau)}d \tau  的运算可以使用复化辛普森公式(此处略)\\
$$



## 缺陷

本方案只给出了简单的求解步骤, 存在许多缺陷

-   没有证明一个大于零的解存在, 在什么时候存在
-   也没有说明牛顿法迭代出的解是否就是大于零的第一个解(这个解才是有意义的, 是通过终点的时间的解)
-   没有进行误差分析
