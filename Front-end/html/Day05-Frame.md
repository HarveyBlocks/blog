# Frame

在一个框架中显示页面

```html
<iframe height="200" src="Day02-head.md" width="200"></iframe>
```

<iframe height="200" src="Day02-head.md " width="200"></iframe>

超链接里的链接在目标frame中显示

```html
<div style="border: 12px black;">
    <iframe height="200" width="200" name="iframe_a"></iframe>
</div>

<a href="Day02-head.md" target="iframe_a">head</a>
```
