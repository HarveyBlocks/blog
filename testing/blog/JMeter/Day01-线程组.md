# 线程组

-   进程
    -   正在指向的程序
-   线程
    -   进程中的执行线索
-   线程组
    -   进程组许多线程, 为方便管理, 对线程按照性质分组
-   一个进程包含多个线程组, 一个线程组包含多个线程
