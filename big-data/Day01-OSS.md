# OSS

> 对象存储服务

远程的, 几乎存储空间无限的, 类似文件系统, 但比文件系统更高级的服务

相较于文件系统的优化

- CDN 缓存
- 传输安全
- 文件压缩
- 图片处理(例如去水印, 在远程即可处理)
- 存储空间无限: 传统的文件管理服务器有存储上限, 而OSS依靠多个可扩展的服务器集群, 采用**分布式元数据管理**和**一致性哈希**技术，将数据和元数据分散到成千上万个存储节点。**不存在单个元数据服务器瓶颈**，可以线性扩展性能和存储容量，轻松支持百亿级对象和超高并发访问
- 元数据和标签管理: 支持用户自定义**对象标签**（Key-Value），并基于标签进行权限控制和生命周期管理。同时提供**元数据索引**能力，支持按任意标签、自定义元数据进行快速检索，即使跨Bucket也能查询。
