# 功能特性和常用功能

## 功能

-   处理静态文件, 静态资源部署
-   处理索引文件, 支持自动索引, 使用Rewirte进行地址重写(正则表达式)
-   提供反向代理服务器
-   可用于缓存
-   负载均衡
    -   轮询
    -   加权轮询
    -   ip_hash
    -   url_hash
    -   fair
-   环境部署
    -   高可用的环境
-   用户认证模块



## 核心组成

-   Nginx二进制可执行文件
    -   启动, 关闭, 重新加载
-   ngixn.conf
    -   配置文件
-   error.log
    -   错误日志记录
-   acess.log
    -   访问日志记录
