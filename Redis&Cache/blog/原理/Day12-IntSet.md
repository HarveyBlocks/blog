# IntSet

>Redis中Set集合的一种实现方式, 基于整数数组来实现, 并且具备**长度可变**, **元素唯一**, **有序**等特征

```c
typedef struct intset {
    uint32_t encoding; /*编码方式, 每个元素所占的字节数, 支持存放16位, 32位, 64位整数*/
    uint32_t length; /*元素个数*/
    int8_t contents[]; /*整数数组, 保存集合数据*/
} intset;
```

默认按照升序放在`constents`数组中

## IntSet升级

>   当一个存入的数据的大小大于当前的编码的最大值的时候, IntSet会自动改变编码方式1. 

1.  判断加入数据的合适的大小
    -   最大值大于当前数值的编码格式的最小值
    -   16位->50000->32位
2.  计算升级后的数组需要的容量大小, 然后扩容数组
    -   一开始是两个字节的元素10个, 申请的内存容量是32个字节
    -   现在变成四个字节的元素11个, 申请内存容量64个
3.  倒序, 依次将数组中的每个元素拷贝到数组中的对应位置
4.  将待添加的数据加入数组
5.  改变Encoding的信息和len信息
