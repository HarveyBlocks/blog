# 多级缓存

>   应对亿级流量的缓存方案

## 概念

充分利用请求处理的每个缓解, 分别添加缓存, 减轻Tomcat压力, 提升性能

1.  浏览器-客户端缓存

    -   浏览器把服务器返回的静态资源缓存在本地

    -   服务器只需要检查数据有没有变化, 没有变化返回`304`状态码

        -   问: 怎么直到两次请求的是一样的数据?

            真的是服务器做这个事情吗?

    -   浏览器接收`304`状态码, 直接用原来的资源

2.  Nginx本地缓存

    -   在Nginx上编写代码, 然后检查Nginx上的缓存
    -   Nginx使用Lua脚本编写业务代码

3.  Nginx和Tomcat之间设置Redis

4.  Tomcat进程缓存

    -   JVM进程缓存

5.  数据库



由此看出, Nginx很重要啊, 不止是反向代理的工作啊, 还需要做业务逻辑啊

所以要搭建Nginx集群, 在设置新的Nginx做反向代理, 管理这个Nginx集群
