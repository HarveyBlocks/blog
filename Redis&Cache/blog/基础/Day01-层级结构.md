# 层级结构

Redis的key允许多个单词形成层级结构, **多个单词用`:`隔开**

```
项目名:业务名:类型:id
```

可以根据自己的需求来删除或添加词条



当有**多个键有用`:`分开来**的是重复的部分, 就会形成

```bash
mset user:id1 1 user:id2 2
```

对对象序列化成JSON字符串之后存储在redis

```json
"user": {
	"age": 1,
    "name": "Mike"
}
```
