## GoRoutine

Go语言的并发是基于goroutine

goroutine类似于线程，但并非线程, 可以将goroutine理解为一种虚拟线程。

Go语言运行时会参与调 度goroutine，并将goroutine**合理地分配到每个CPU中**，最大限度地使 用CPU性能。

## channel

多个goroutine中，Go语言使用channel进行通信

将需要并发的程序设计为生产者和消费者的模式，将数据放入通道

通道的另外一端的代码将这些数据进行并发计算并返回结果



## Hello World

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}
```

### package

*`package main`* 定义了包名

在源文件中非注释的第一行指明这个文件属于哪个包

表示一个可独立执行的程序

**每个 Go 应用程序都包含一个名为 main 的包**

语法:

```go
package 包名
```

文件夹名和包名没有直接的关系, 同一个文件夹下不能有多个包, 否则编译报错

### import

 *`import "fmt"`*  表明这个程序需要使用 fmt 包的函数，或其他元素

fmt 包实现了格式化 IO 的函数。

语法:

```go
import "包名"
```

### func

*`func main()`* 是程序启动的入口

每一个可执行程序必须包含main函数

```go
func main() 
{ // 将导致错误
    fmt.Println("Hello, World!")
}
```



### 注释

### 标识符

>   常量、变量、类型、函数名、结构字段等

标识符以一个大写字母开头，那么该对象就可以被外部包的代码所使用(需要先导入这个包)

这被称为导出

标识符如果以小写字母开头，则对包外是不可见的, 在整个包的内部是可见并且可用的

## 执行Go程序


```shell

```


Go编译器自动将行分隔符`;`加在句子末尾

如果要将多个语句写在同一行, 就自己加`;`

如果要把一个语句写在多行.....也行, IDE会给出一些提示, 但规律暂未知
