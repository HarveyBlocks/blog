## 数字

整型 int

### 整形





| 数据类型 | 描述                          |
| -------- | ----------------------------- |
| int          | 取决于CPU字长, 32位 or 64位|
| int8         | 有符号 8 位整型 (-128 到 127)|
| int16        | 有符号 16 位整型 (-32768 到 32767)|
| int32        | 有符号 32 位整型 (-2147483648 到 2147483647)|
| int64        | 有符号 64 位整型 (-9223372036854775808 到 9223372036854775807) |
| uint         | 取决于CPU字长, 32位 or 64位|
| uint8        | 无符号 8 位整型 (0 到 255)|
| uint16       | 无符号 16 位整型 (0 到 65535)|
| uint32       | 无符号 32 位整型 (0 到 4294967295)|
| uint64       | 无符号 64 位整型 (0 到 18446744073709551615)|

### 浮点型

| 数据类型 | 描述                          |
| -------- | ----------------------------- |
| float32      | IEEE-754 32位浮点型数|
| float64      | IEEE-754 64位浮点型数|

### 复数


| 数据类型 | 描述                          |
| -------- | ----------------------------- |
| complex      | 复数的抽象概念|
| real         | 复数实部, IEEE-754浮点数表示|
| imag         | 复数虚部, IEEE-754浮点数表示|
| complex64    | 实部和虚部各占32位, 各自用浮点型存储|
| complex128   | 实部和虚部各占64位, 各自用浮点型存储|

### 其他


| 数据类型 | 描述                          |
| -------- | ----------------------------- |
| rune         | 用来处理UTF-8 编码的 Unicode字符, 长度不定, 一个字符, 一个rune |

## 类型转换

### 语法

```go
转换类型后的对象 = 目标类型(原对象)
```

```go
var num1 int16 = 0x7f77
var num2 int16 = -num1
fmt.Printf("%b\n", num1)              // 0111_1111_0111_0111
fmt.Printf("%b\n", num2)              // -0111_1111_0111_0111
fmt.Printf("%b\n", uint16(num1))      // 0111_1111_0111_0111
fmt.Printf("%b\n", uint16(num2))      // 1000_0000_1000_1001
fmt.Printf("%b\n", uint8(num1))       // 0111_0111
fmt.Printf("%b\n", uint8(num2))       // 1000_1001
fmt.Printf("%b\n", int8(num1))        // 0111_0111
fmt.Printf("%b\n", int8(num2))        // -0111_0111
fmt.Printf("%b\n", int8(uint8(num2))) // -0111_0111
fmt.Printf("%b\n", uint8(int8(num2))) // 10001001
```

高->低, 直接从低位夹断

同长度, 有符号->无符号 编码转换, 值不变

浮点->整形: 去除小数部分
