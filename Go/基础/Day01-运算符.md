无前置++/--, 后置++/--不能赋值给变量

| 优先级 | Operator       | Description    | Associativity |
| :----: | :------------- | :------------- | :------------ |

|        | `()`           | 函数调用       | 自左向右      |

|        | `.`            |                | 自左向右      |
|        | `->`           |                | 自左向右      |

|        | `!` `^`        | 逻辑非和位取反 | 自右向左      |

|   3    | `*` `/` `%`    |                | 自左向右      |
|   4    | `+` `-`        | 加减号         | 自左向右      |

## 异或与取反

都是`^`

```go
var num byte = 0xff
fmt.Printf("%b\n", num) // 11111111
num = ^num              // 取反
fmt.Printf("%b\n", num) // 0
num = 0xf
fmt.Printf("%b\n", num) // 1111
num = 0xf0 ^ num        // 异或
fmt.Printf("%b\n", num) // 11111111
```

## 移位

带符号的移位

```cpp
var num int32 = -1
fmt.Printf("%d\n", num)    // -1
fmt.Printf("%d\n", num>>1) // -1
```
