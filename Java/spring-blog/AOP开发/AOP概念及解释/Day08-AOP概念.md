# AOP

>   Aspect Oriented Programing

-   面向切面编程
    -   是面向对象(OOP)的升华
    -   功能的横向切取,主要靠Proxy实现
    -   面向对象编程是纵向设计一个Bean,AOP是横向抽取功能的思想

-   AOP是横向的堆不同事物的抽象
-   属性与属性,方法与方法,对象与对象都可以组成一个切面
-   而用这种思维去设计编程的方式叫做面向切面编程

-   在很多对象当中
-   我们可能要抽取每个对象当中的一部分功能
-   再临时组装成一个???
-   再去执行
