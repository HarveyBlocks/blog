# List实现类

## ArrayList[重点]

- 数组结构实现
  - 查询快,增减慢
- 运行效率高,线程不安全

## Vector

- 数组结构实现
  - 查询快,增减慢
- 运行效率慢,线程安全

## LinkedList

- 链表结构实现
  - 查询慢,增减块

## 为什么数组和链表有这些特点

为什么数组查询快,增减慢;链表查询慢,增减块

查询:

数组的存储空间是**连续**的,只要先知道数组的位置,在与索引一通计算猛如虎,就可以直接得到元素

链表的存储空间是**离散**的,知道头指针后,只能通过该元素指向下一个节点的指针一个一个的**摸石头过河**



增减:

数组增减需要把后面往后移,或往前移
