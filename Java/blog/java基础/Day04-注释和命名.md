# 注释和命名

## 注释

### 单行注释

``` java
// 这是单行注释
```

### 多行注释

```java
/*
这是多行注释
你想怎么注
你就可以怎么注
*/
```

### 文档注释

``` java
/**
 * @author 27970 
 * @version 1.0
 * @since 1.8
 * 
 * 
 */

public class Main {
    
    /**
     * @author 27970
     * @version 1.0
     * @since 1.8
     *
     *
     */


    public static void main(String[] args) {
        
        }
    }
}
```

## 命名标识符的规则

1. 应以字母A-Z（或a-z），“$”，下划线“_”开头
2. 首字母以后是字母，“$”，下划线“_”，数字的任意字母组合
3. 可用中文命名（**不规范**）
4. 不能含有特殊符号（%，&，*等）
5. 标识符是大小写敏感的

## 命名规范

| 对象          | 命名原则             | 例子              |
| ------------- | -------------------- | ----------------- |
| 方法名/变量名 | 首字母小写的驼峰原则 | monthSalaryBeLike |
| 常量          | 下划线+全大写        | MAX_VALUE         |
| 类名          | 首字母大写的驼峰原则 | GoodMan           |
|               |                      |                   |
