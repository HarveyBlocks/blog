# 泛型概述

**Generic**

- Java泛型是JDK1.5中引入的一个新特性
- 其本质是参数化类型(八大基本类型×),把类型作为参数传递
- 常见形式有泛型类(集合大多是泛型类),泛型接口,泛型方法
- 语法:
  - <T....> 	T称为类型占位符,表示一种引用类型
- 好处:
  - (1) 提高代码的重用性
  - (2) 防止类型转换异常(?),提高代码的安全性

## 本质

参数化类型(八大基本类型×),把类型作为参数传递

- 我想可以这么理解:
  - <>内定义了一个(或多个)泛型通配符
  - 若该类/接口/方法中出现未定义的通配符,就报错,
  - 声明的作用域就时所在(类/接口/方法)
  - 如果泛型(类或接口)中有泛型方法,且定义的泛型类占位符冲突:
    - 以作用域小(方法)的内定义的泛型类

## 常见形式

泛型类(集合大多是泛型类)

泛型接口

泛型方法

## 语法

``` java
	<类型占位符[,....]>
```

T称为类型占位符,表示一种引用类型

还可以是E,K,V

| 类型占位符 | 源      | 意   | 描述             |
| ---------- | ------- | ---- | ---------------- |
| T          | Type    | 类型 | 表示一种引用类型 |
| E          | Element | 元素 |                  |
| K          | Key     | 键   |                  |
| V          | Value   | 值   |                  |

- 也叫通配符
- <>里填啥都行什么shit啊,fuck啊,都行,没啥区别
- 填以上这些是约定俗成,增加程序可读性
