# final

## 修饰变量

- 不能再赋值

```java
final double PI=3.14159265358979323;
```

## 修饰方法

被称为**最终方法**

- 不能被重写

## 修饰类

``` java
public final class Person{
    
}
```

一个类被final之后就不能被继承



## 注意

- final修饰基本变量类型的变量,变量存储的**数据**不能改变
- final修饰引用变量类型的变量,变量存储的**地址**不能被改变,但地址所指向的**对象**可以被改变

什么用呢?示例如下:

```java
final int[] nums = {1, 2, 3};
nums[1] =4;
System.out.println(nums[1]);//4
```

## 常量

- 被static final修饰的变量称为常量
- 作用:常用于记录系统的配置信息

- 命名规范:全_大写

### 常量优势

- 代码可读性好

因为用代码名,有了具体的意义

- 代码可维护性好

如果用了常量,只要改了最上面,就一改全改了

- 程序编译后,常量会被**宏替换**出现常量的地方全部会被替换成其记住的字面量
- 可以保证常量和直接使用字面义达到同样的效果
