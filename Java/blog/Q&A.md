### 为什么要抛出异常? 异常在什么时候抛出 ?

程序不是最好不要产生错误吗? 为什么还要自己产生错误来?

其实是在程序的设计中, 我们往往只负责一个模块, 而不是一整个系统. 因此对于某一个单独的模块来说, 不知道外界使用这个模块的时候, 是怎么一个使用法. 如果发生了出乎意料的使用了怎么办?

比如我们的工作设计一个自己的数组类

```java
class MyIntArray {
    private final int[] arr;
    public MyIntArray(int length){
        this.arr = new int[length];
    }
    public MyIntArray(int... arr){
        this.arr = arr;
    }
    int get(int index) {
    	return arr[index];
    }
    int set(int index, int value){
        int old = arr[index];
        arr[index]  = value;
        return old;
    }
}
```

我们的合作者, 这个类的调用者会如何使用? 我们无法得知. 

```java

        MyIntArray arr = new MyIntArray(-2);

    }
}
```

### 为什么 Java 选择了泛型擦除 ?

- C++ 有模板, 功能和泛型类似.
- 模板在编译期将类参数注入模板类中, 然后进行编译. 
- 也就是说, C++是真的是一个模板类会编译出一个类出来的.
- 也因此, C++支持类似`list<int>`的语法, 而Java做不到, Java只能进行 `List<Integer>`, 而Integer是8Byte的引用对象, 有一半的浪费.

## 高级特性

### 注解有什么用 ?

注解本身不发挥直接的作用, 它是和反射联合起来使用的

在类/方法/字段等上标注了的注解, 可以通过反射给获取到. 这样, 代码就能知道哪个类/方法/字段等上标注了什么注解. 

比如说一个注解在方法上是 `@Log` , 作用是在方法调用前后输出方法名, 调用时间, 输入参数值和返回的值. 那么这就需要一个"注解扫描工具", 去扫描有注解`@Log`的方法, 然后记录这个方法, 然后每次这个方法调用的前后, 都去做有关的工作.
