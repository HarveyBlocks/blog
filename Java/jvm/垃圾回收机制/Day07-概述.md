# 垃圾回收

>   Garbage Collection GC

垃圾回收机制, 通过垃圾回收器来对不再使用的对象完成自动的回收, 垃圾回收器主要负责对堆上的内存进行回收.

Go, Python, C#都有垃圾回收机制

## 优缺点

-   优点
    -   降低程序员实现难度, **降低**对象回收bug的可能
-   缺点
    -   程序员无法控制内存回收的及时性

## 应用场景

-   系统僵死问题
    -   频繁的垃圾回收, JVM忙于垃圾回收, 无从应对用户请求
-   性能优化
    -   对垃圾回收的配置

## 手动触发垃圾回收

只是一个对JVM虚拟机垃圾回收的建议, 不见得真的会触发垃圾回收

```java
System.ge();
```

## 查看信息

```shell
-verbose:gc
```
