# 程序计数器

>   Program Counter Register PC寄存器

线程不共享

每个线程会通过程序计数器记录当前要执行的字节码指令的地址

解释器向程序计数器请求指令的内存地址, 则可获取字节码指令并执行

## 执行流程

1.  程序计数器指向第一行指令所在位置

2.  解释器获取到指令地址

3.  执行指令

4.  程序计数器+1

5.  解释器获取到指令地址

6.  执行指令

    发现是分支结构/循环结构/异常/goto跳转

    指导程序计数器指向正确的指令

7.  程序计数器指向对应指令

    ...

## 多线程

多线程的情况下, Java虚拟机需要通过程序计数器记录CPU切换前解释执行到那一句指令并继续解释执行

## 内存溢出

程序在使用某一块内存区域时, 存放的数据需要占用的内存大小超过了虚拟机能提供的内存上限

程序计数器在运行过程中会出现内存溢出吗

**一台64位的电脑分配给程序计数器的命令地址大小是8个字节**

不会, 程序计数器只会存储一个固定长度的内存地址
