# 数据传输

当前的Java-Agent的是将控制和展示全部都显示在实际运行的项目中的

这和Arthus的运行状况明显不同

Arthus有自己的客户端, 能够控制和实际项目整合的JavaAgent

Arthus的做法是网络通信, 与项目结合的JavaAgent的部分是个黑盒, 不做数据输入输出, 仅仅对项目进行监控和数据运算

数据的结果最终还是交由客户端进行展示

也就是说, 用户在客户端进行指令的输入, 客户端通过网络传输将数据传输给Arthus的JavaAgent(与项目绑定), JavaAgent在神不知鬼不觉之间完成了对当前JVM信息的获取, 或对JVM的控制, 然后将结果相应给客户端

这一来一回, 就是请求-响应的模式(即使服务端和客户端都在本地)
