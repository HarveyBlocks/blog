# 缓存雪崩

同一时段内, 有大量的key同时失效(例如一瞬间几万key过期), 或者Redis服务当值, 导致大量请求到达数据库, 造成巨大压力

## 解决方案分析

-   数万key同时过期

    -   例如为了做服务器的预热, 我们可能会往缓存中**批量导入数据**
    -   解决方案: 把随机值(25+Random(10)作为key的TTL

-   Redis宕机

    对于宕机的解决方案不是无非找个备用机顶替呗(又要纠结到读写一致性问题)

    -   利用Redis集群提高服务的

        Redis的哨兵机制, 也可以让主从实现数据的同步

-   整个机房炸了

    -   逆天

    -   给缓存业务添加**降级限流**策略

        服务降级

        发现Redis宕机后立刻拒绝对一部分请求的服务, 牺牲一部分的服务来保护数据库的健康

-   给业务添加多级缓存
