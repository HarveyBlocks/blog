# 概念

## 进程

加载指令, 管理IO

一段程序被运行, 代表开启了一个**进程**

程序是静态的, 进程是真正运行的过程, 是动态的, 可看作程序的实例

一个程序内部也能启动其他程序, 一个程序利用内部的控制, 其反复"启动"其实并没有开启新的一个进程

##进程

一个进程内可以分为多个线程

一个线程就是一个指令流

## 线程与进程

进程相互独立, 线程是进程的子集

-   资源
    -   线程作为最小的调度单位, 从线程中获取指令
    -   进程是资源分配的最小单位, 管理IO, 内存是进程控制和管理的, 线程之间贡献内存

-   通信
    -   同一台计算机的**进程通信**称之为`Inter-process Communication ` (IPC)
    -   **线程的通信**方式更轻量, 例如共享变量
    -   计算机之间的通信使用网络

## 并发

操作系统利用任务调度将CPU的时间片分给不同的程序来执行

CPU的时间片很短(windows下最小约15ms)

并行的操作在CPU的角度, 是串行的, 但是由于间隔太小, 在宏观上就有了同时运行的现象

也就是说, 单核CPU, 即使在软件层面使用了多线程, 也没办法提高效率

##并行

>Rob Pike: 
>
>并发（concurrent）是同一时间应对（dealing with）多件事情的能力
>
>并行（parallel）是同一时间动手做（doing）多件事情的能力

多核CPU下, 可以不理会单独CPU的时间线的间隔限制, 而将CPU资源同时分配给不同的程序来执行

真正意义上的同时进行

## 异步调用

-   同步
    -   方法的调用者需要方法的返回值才能继续执行
-   异步
    -   方法的调用者不需要方法的返回值也能继续执行
