# JMM

>   Java Memory Model

JMM定义了主存(堆内存, 所有线程共享) , 工作内存(线程独有)的抽象感念

底层对应CPU寄存器, 缓存, 内存, CPU指令优化

-   原子性
    -   保证指令不会收到线程上下文切换的影响
    -   [管程](../共享模型/Day02-管程.md)
-   可见性
    -   指令不会收到CPU缓存/内存缓存而导致的读写不一致的情况
    -   [可见性](./Day05-可见性.md)
-   有序性
    -   保证指令不会收到CPU指令并行优化的影响
    -   JIT 代码重排序
    -   [有序性](./Day05-有序性.md)
