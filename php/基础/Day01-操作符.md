# 操作符

- 算术运算符

- 字符串运算符

- 赋值运算符

- 比较运算符

  - 严格等于`===`
  - 严格不等于`!==`
  - 不等于, 有 `<>` 和 `!=`

- 逻辑运算符

  - 有 `and` 风格的, 也有 `&&` 风格的

- 位运算符

- 其他运算符

  - `.` 字符串拼接运算符

    ```php
    $str = 'hello ' . $name; // hello Administer
    $str = 1 . 1; // 11
    ```
  
  注意数字要拼接字符串的时候
  
  ```php
  $str = 1. 's';//ERROR, `1.` 算一个数字, . 算小数点
  $str = 1 . 's';//ERROR, `.` 算字符串拼接运算符
  ```
  
  
  
- 三元运算符`?:`
  
- 错误控制运算符`@`
  
  - 执行运算符 ` `` `

## 错误控制运算符

放在变量/函数调用/常量等之前

不能放在函数或类的定义之前, 不能放在控制结构之前

```php
@echo''; // 不允许
@print ''; // OK
```

忽略这个表达式可能产生的任何错误
