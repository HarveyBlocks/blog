# 比较排序

通过比较数组中任意两个元素的大小来执行排序的, 称为比较排序法

插入排序, 堆排序, 冒泡, 并归排序, 快速排序, 都是比较排序

比较排序可以被决策树抽象

## 决策树

决策树是一棵完全二叉树(?没有吧?)

![image-20240619011537791](../../assets/Day02-%E6%AF%94%E8%BE%83%E6%8E%92%E5%BA%8F/image-20240619011537791.png)

该图是三个元素使用插入排序的过程, 在决策树上的体现

LL表示: A[1]<A[2], A[2]<A[3]=> [A[1],A[2],A[3]]

LRR表示:A[1]<A[2], A[2]>A[3], A[1]>A[3]=>[A[3],A[1],A[2]]

由决策树, 可证明任意比较排序算法的时间复杂度都大于O(nlogn)
