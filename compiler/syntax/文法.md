# 文法

## 上下文无关文法

正则表达式也是一种上下文无关文法

- T: 该语言的终结符/tokens
- NT: 非终结符. 指示该文法&在该语言中可生成的串的集合
- S: 开始符号, $S\in NT$, 定义该语言的所有串
- PR: 产生式规则, 用于指示 T 和 NT 如何结合以生成该语言的合法串

$$
\begin{align}
    PR: NT &\to (T|NT)*
\end{align}
$$



ETC.
$$
\begin{align}
    expression &\to\; expression + term \\
    			&|\; expression - term \\
    			&|\; term \\
    term  	   &\to\; term * factor \\
    			&|\; term / factor \\
    			&|\; factor \\
    factor	   &\to\; (expression) \\
    			&|\; id \\
    			&|\; constant
\end{align}
$$

## Derivation推导

文法规则应用和替换的一个序列，它转换一个起始的非终结符称为一个终结符/token的**集合**

![image-20260327113226532](https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/theory/image-20260327113226532.png)





设 $G$ 是开始符号为 $S$ 的一个上下文无关文法，那么  $S \to W$ (其中 $W$ 中没有非终结符) 表示由 $G$生成的语言， 记为 $L(G)$. 

于是  $W \in L(G) \Leftrightarrow S \Rightarrow W $

- 句子, 包含终结符的句型.
- 句型, 当 $S\Rightarrow\alpha$ (且 $\alpha$ 中可以有非终结符), 它被称为 $G$ 的一个句型. 开始符和句子也是句型. 
- lm:  `leftmost derivation`, 最左推导. 指最左侧的T优先进行推导

## 二义性文法

对于同一个表达式, 同时使用最左推导, 却可以产生两棵树

<img src="https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/theory/image-20260327114300812.png" alt="image-20260327114300812" style="zoom:50%;" />

以及

<img src="https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/theory/image-20260327114315560.png" alt="image-20260327114315560" style="zoom:50%;" />

对于这种二义性文法的消除, 要么修改文法的表述, 要么在程序中选择哪棵文法树

常见二义性如 $S\;\to \;S \;(\;S\;)\;S\;|\;\epsilon$ 在生成括号 `()()` 时具备二义性, 转化为 $S\;\to\;(\;S\;)\;S\;|\;\epsilon$ 消除了二义性

例如条件表达式
$$
\begin{align}
    stmt &\to\; if\; expr\; then\; stmt\\
         &|\;  if\; expr\; then\; stmt\; else\; stmt\\
         &|\;  other\\
    other &\to\;any\; other\; statement\;
\end{align}
$$


![image-20260327115213460](https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/theory/image-20260327115213460.png)

消除二义性
$$
\begin{align}
    stmt &\to\; \\
    	&matched\_stmt\;|\; unmatched\_stmt;\\
    matched\_stmt &\to\;\\
    	&if\; expr\; then\; matched\_stmt\; else\; matched\_stmt\;|\; other; \\
    unmatched\_stmt &\to\; \\
    	&if\; expr\; then\; stmt ;|\;  if\; expr\; then\; matched\_stmt\; else\; unmatched\_stmt; \\
\end{align}
$$


- **matched_stmt**：已经匹配好的语句，即每个 `then` 都有对应的 `else`（或者是不含 `if` 的 `other` 语句）。这种语句不会造成悬空 else。
- **unmatched_stmt**：未匹配的语句，即其中至少有一个 `then` 后面缺少对应的 `else`。

## CFGs 和 CFLs

- **CFGs** 上下文无关语言

- **CFLs**  上下文有关语言

正则表达式是最小最容易定义的语言类, 即使在上下文无关语法中也是最简单的

考虑一种语言的描述 $a^nb^n$ 表示, a有几个, b就有几个, 那么就匹配

这其实依旧是在描述一种上下文无关语法, 因为这段字符是否匹配已经完全被定义了. 但是这种字符串**无法被正则表达式描述**. 因为正则表达式无法记录 `n` 这种数字

换种方式来说, REs 能转换成 NFA/DFA, FA 作为 **有穷** 状态机, 状态个数是有限的, 而 **n** 的数量, 可以理解成无穷个数的状态, 因此 REs 无法表达这种语言

## 对象抽象

把文法本身抽象成对象

```java
class  GrammarSymbol {
    String name;
    boolean terminal;
}
class  GrammarConcatenation { // 连接(.)
    List<Symbol> concatenation; // 0 for epsilon(specilly)
}
class  GrammarAlternation { // 选择(|)
    List<GrammarConcatenation> alternation; // 1 or more
}

class GrammarProduction{
    Symbol left;
     GrammarAlternation right;
}
```
