## 递归下降

基于输入符号选择产生式规则

可能要求回溯以纠正错误的选择

以文法
$$
\begin{align}
    S&\to\;c\;A\;d\\
    A&\to\;a\;b\;\mid\;a\\
\end{align}
$$
输入: `cad` 为例构造AST: 

![image-20260329160841414](https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/theory/image-20260329160841414.png)

最后的A下漏了`a`

递归下降算法

```cpp
算法: 递归下降解析过程（对应非终结符 A）

输入: 当前输入位置指针
输出: 是否成功匹配 A 对应的语法结构

function A(){
    从 A 的多个产生式中选择一个产生式: A->X[0]X[1]X[2]...X[k];
    for (i = 0; i < k; i++){
        if (not X[i].terminal) {// x[i] 是一个非终结符
        	X[i].invoke(); // 调用该非终结符对应的过程  
        } else if (X[i] == input.peek()){
        	input.next();
        } else {
            error; // 跳过 or 上报 or 回溯 or 终止算法
        }
        
    }
}
```

以
$$
\begin{align}
    E&\to\;T\;E'\\
    E'&\to\;+\;T\;E'\;\mid\;\epsilon\\
    T&\to\;F\;T'\\
    T'&\to\;*\;F\;T'\;\mid\;\epsilon\\
    F&\to\;\;(E\;)\;\mid\;id
\end{align}
$$
为例, 递归代码为:

```cpp
main(){
    E();
}
E(){
    T();
    E1();
}
T(){
    F();
    T1();
}
E1(){
    token = input.peek();
    if(token == '+'){
        input.next();
        T();
        E1();
    } else {
        // epsilon do nothing
    }
}
T1(){
    token = input.peek();
    if(token == '*'){
        input.next();
        T();
        E1();
    } else {
        // epsilon do nothing
    }
}
F(){
    token = input.peek();
    if(token == '('){
        input.next();
        E();
        match(')');
    } else if(token in id){
        input.next();
       	// for id
    } else {
        error
    }
}
```



## 预测语法分析 : 非递归

利用**当前的输入符号**, 与**要被扩展的非终结符**相结合以**唯一确定下一动作**.

但是需要文法满足下面的前提:  

- 消除左递归
- 消除左公共因子
- 消除$\epsilon-move$

构造**转移图,** 即可依照转移图构造解析代码

方法是对该文法的每个**非终结符**进行如下操作:

1. 建立一个初始和最终的状态
2. 如果 $A\to X_1\;X_2\;X_3\;\dots\;X_n$ 是产生式, 增加边为 $X_1, X_2, X_3, \cdots, X_n$的路径

图中的循环(状态之间的回路), 对应着文法中的递归结构(左递归或右递归)

构造转移图转换成 **预测分析表**, 即可**机械**地进行**预测语法**



## 构造分析表

1. 关于文法计算 `First` 及 `Follow` 集合
   - `First(α)` 是终结符集合, 可能包含 $\epsilon$
   - `Follow(A)` 是终结符集合, 可能包含 $\$$, 但不包含 $\epsilon$
   - `$` 是输入串的结束标记（end marker），也叫文件结束符
2. 引用关于分析表的建造算法

`First`:

设 $\alpha$ 是文法符号串. 

$First(\alpha)$ 是在 $\alpha$ 的任一可能推导中出现的第一个打头的终结符.

- 例如 $A\to B\; c$, $B\to d$, 那么 $B\;c\Rightarrow d\;c$, 那么终结符 $d$ 就是所谓 $First(\alpha)$
- 对于 $\alpha$ 是终结符的情况, $F(\alpha) = \{\alpha\}$

注意: 如果 $\alpha \overset{*}{\Rightarrow} \epsilon$ ($\overset{*}\Rightarrow$ 表示经过 0 步或多步推导), 则 $\epsilon$ 属于 $First(\alpha)$

`Follow`:

设 $A$ 是非终结符, $a$ 是终结符, $\alpha$ & $\beta$ 是任意可空文法符号串 

$Follow(A)$ 是所有**句型**中直接出现在 $A$ 的右边的终结符 $a$ 的集合.

$S\overset{*}\Rightarrow\alpha Aa\beta$, 则 $a \in Follow(A)$

注意: 如果 $S\overset{*}\Rightarrow\alpha A$, 则 $\$$ 属于 $Follow(A)$

### 计算 `First(X)`

1. 如果 $X$ 是终结符, 则 $First(X) = \{X\}$
2. 如果有产生式 $X \to \epsilon$, 则 add $\epsilon$ to $First(X)$
3. 如果 $X$ 非终结符, 且有产生式 $X\to Y_1Y_2\dots Y_k\dots Y_n$ 
   1. 令 $k=1$
   2. 将 $\text{First}(Y_k)$ 中除 $\epsilon$ 外的所有终结符加入 $\text{First}(X)$。
   3. 如果 $\epsilon\in \text{First}(Y_k)$ , $k \leftarrow k  + 1$, 返回步骤二
   4. 如果 $\epsilon\notin \text{First}(Y_k)$（即 $Y_k$ 不能推导出 $\epsilon$）, 则停止该算法
   5. 如果所有 $Y_1, Y_2, \dots, Y_n$ 的 $\text{First}$ 集都包含 $\epsilon$，则将 $\epsilon$ 加入 $\text{First}(X)$。



又对于 $\mathrm{First}(X_1 X_2 \dots X_n)$
$$
\mathrm{First}(X_1 X_2 \dots X_n) = \bigcup_{i=1}^{n} \mathrm{First}(X_i)
\quad\text{ 对于所有 } j < i,\; \varepsilon \in \mathrm{First}(X_j)
$$



### 计算 `Follow(X)`

规则定义 Follow 集：

1. $\$ $ 加入 $ \text{Follow}(S)$，$S$ 是开始符号。  
2. 若存在 $B \to \alpha A \beta$，则 $(\text{First}(\beta) - \{\epsilon\})$ 加入 $\text{Follow}(A)$。  
   - $\alpha$ 代表的是一系列符号，可以是由终结符、非终结符或者空串（$\epsilon$）构成的序列。
   - $A$ 后面有 $\beta$，则 $\beta$ 能推导出的第一个终结符跟在 $A$ 后。
   - 如果 $\text{First}(\beta)$ 中的 $\epsilon$ 不会加入 $\text{Follow}(S)$, 因为 $\epsilon$ 不能指示读入的下一个输入
3. 若 $B \to \alpha A$，或 $B \to \alpha A \beta$ 且 $\beta \overset*\Rightarrow \epsilon$，则将 $\text{Follow}(B)$ 加入 $\text{Follow}(A)$。
   - 若 $A$ 在右部末尾, 则 $A$ 后面能出现的终结符至少需要包含左部 $B$ 后面会出现的终止符。
   - 若 $A$ 后面的 $\beta$ 可为空, 即取 $A\to\epsilon$ 效果等价于 $B\to\alpha A$

计算Follow(X)的算法

重复如下步骤直到对任何 Follow-set 都没有变化发生

```cpp
对于任一产生式 X->Y[0]Y[1]Y[2]...Y[m-1]
if(Y == epsilon){
    return;
}
for(i = 0;i < m;i++){
	if(Y[i].isTerminal){
        // 规则 2 和 3 只关心非终结符
		continue;
	}
    // 规则 2
    Follow(Y[i]) cup= First(Y[i+1]...Y[m-1]) - {epsilon};
    // 规则 3
    if(epsilon in First(Y[i+1]...Y[m-1])){
        Follow(Y[i]) cup= Follow(X)
    }
}
```

- 规则二依赖的 `First(β)` 是**静态**的，不随迭代变化。所以只需**第一轮**扫描所有产生式，规则二贡献的符号就全部确定了，后续轮次不会再有新符号从规则二加入。
- 规则三传播的是 `Follow(A)`，而 `Follow(A)` 可能被别的规则三更新，所以需要反复执行直到稳定。

**第一轮同时做规则二和规则三；从第二轮开始只需反复做规则三，直到没有变化为止**。这是Follow算法的一个有效优化，很多教材和实现确实这么处理（比如显式区分“初始化”和“传播”阶段）。





### 构造分析表

构造分析表 $M$, 对于每条规则 $A\to \alpha$，重复以下步骤：

1. 如果终结符 $a$ 在 $\text{First}(\alpha)$ 中，则将  $A\to a$ 添加到预测分析表 $M[A, b]$。
2. 如果空串 $\epsilon$ 在 $\text{First}(\alpha)$ 中，则：

   1. 对于所有 $\text{Follow}(A)$ 中的终结符 $b$，将$A\to \alpha$ 添加到 $M[A, b]$。
   2. 如果 $\$$ 在 $\text{Follow}(A)$ 中，且 $\epsilon$ 在中 $\text{First}(a)$ ，则将 $A\to \alpha$ 添加到 $M[A, b]$。
3. 对于所有未定义的项，标记为错误。

## 预测分析

### LL(1)

- **L**: Left to right
- **L**: Leftmost derivation
- **(1)** : One symbol of lookahead

LL(1) 文法的性质: 

文法不是二义的或左递归的

文法是 LL(1) $\Leftrightarrow$ 当 $A \rightarrow \alpha \mid \beta$

1. $$\text{FIRST}(\alpha) \cap \text{FIRST}(\beta) = \emptyset$$。
2. $$\varepsilon \in \text{FIRST}(\alpha)$$ 与 $$\varepsilon \in \text{FIRST}(\beta)$$ 不能同时成立。
3. 如果 $\beta \overset*\Rightarrow \epsilon$, 那么 $\text{Follow}(A) \cap \text{First}(\alpha) = \emptyset$

注意: 并非所有非二义性的文法都能通过改写（如消除左递归、提取左公因子等）变成等价的 LL(1) 文法






### 表驱动

下图是表驱动的预测分析

![image-20260331225547858](https://raw.githubusercontent.com/HarveyBlocks/blog_assets/refs/heads/main/compiler/syntax/自顶向下/image-20260331225547858.png)

- $X$ 表示栈顶符号
- $a$ 表示当前输入
- $M$ 表示分析表
- $\$$ 表示终结符

表驱动的预测分析算法:

0. 初始化栈, $\$$ 入栈, 非终结符 **S** 入栈
1. 当 $X=a=\$$ 停止分析, 接受, 成功
2. 当 $X$ is terminal 且 $X = a \neq \$$, 弹出 $X$, **前进输入**, goto 1
3. 当 $X$ not terminal, 查表 $M[X,a]$
   - 表项显示 `error` -> 执行错误恢复
   - 表项产生 $X\to UVW$
     1. $X$ 出栈
     2. 右部符号逆序入栈 $W$, $V$, $U$
     3. **不消费输入**
     4. goto 1
   - 表项产生 $X\to\epsilon$
     1. $X$ 出栈
     2. **不消费输入**
     3. goto 1

## First 计算实例

以
$$
\begin{align}
    E&\to\;T\;E'\\
    E'&\to\;+\;T\;E'\;\mid\;\epsilon\\
    T&\to\;F\;T'\\
    T'&\to\;*\;F\;T'\;\mid\;\epsilon\\
    F&\to\;\;(E\;)\;\mid\;id
\end{align}
$$
为例

### 第一步：基础终结符

$$
\begin{aligned}
\text{First}(+) &= \{+\} \\
\text{First}(*) &= \{*\} \\
\text{First}(() &= \{( \} \\
\text{First}()) &= \{ ) \} \\
\text{First}(id) &= \{id\}
\end{aligned}
$$

### 第二步：F

产生式：`F → ( E )` 和 `F → id`  

- 从 `( E )` 得：`First(() = {(}` → 加入 `{(}`  
- 从 `id` 得：`First(id) = {id}` → 加入 `{id}`  

无 $\epsilon$ 产生式。

$$
\text{First}(F) = \{(, id\}
$$



### 第三步：T'

产生式：`T' → * F T'` 和 `T' → ε`  

- 从 `* F T'` 得：`First(*) = {*}` → 加入 `{*}`  
- 从 `ε` 得：加入 `ε`  


$$
\text{First}(T') = \{*, \epsilon\}
$$

### 第四步：T

产生式：`T → F T'`  

- `First(F) = {(, id}` 不含 `ε`，所以只取 `First(F)`，不继续看 `T'`。  

$$
\text{First}(T) = \{(, id\}
$$



### 第五步：E'

产生式：`E' → + T E'` 和 `E' → ε`  

- 从 `+ T E'` 得：`First(+) = {+}` → 加入 `{+}`  
- 从 `ε` 得：加入 `ε`  

$$
\text{First}(E') = \{+, \epsilon\}
$$



### 第六步：E

产生式：`E → T E'`  

- `First(T) = {(, id}` 不含 `ε`，所以只取 `First(T)`。  

$$
\text{First}(E) = \{(, id\}
$$

### 最终结果

$$
\begin{aligned}
\text{First}(E) &= \{(, id\} \\
\text{First}(E') &= \{+, \epsilon\} \\
\text{First}(T) &= \{(, id\} \\
\text{First}(T') &= \{*, \epsilon\} \\
\text{First}(F) &= \{(, id\}
\end{aligned}
$$



## Follow 计算实例

### 已知文法及 First 集

文法：
$$
\begin{aligned}
E &\to T E' \\
E' &\to + T E' \mid \epsilon \\
T &\to F T' \\
T' &\to * F T' \mid \epsilon \\
F &\to ( E ) \mid id
\end{aligned}
$$

First 集：
$$
\begin{aligned}
\text{First}(E)   &= \{ (, id \} \\
\text{First}(E')  &= \{ +, \epsilon \} \\
\text{First}(T)   &= \{ (, id \} \\
\text{First}(T')  &= \{ *, \epsilon \} \\
\text{First}(F)   &= \{ (, id \}
\end{aligned}
$$



### 初始化

选定E为文法的开始
$$
\text{Follow}(E) = \{\$\},\quad \text{其他 Follow} = \emptyset
$$

### 第一轮

1. **产生式 $E \to T E'$**  
   - 对 $T$：后缀 $E'$，$\text{First}(E')-\{\epsilon\} = \{+\}$ → $\text{Follow}(T) \cup\!= \{+\}$ 
     $\epsilon \in \text{First}(E')$ ⇒ $\text{Follow}(T) \cup\!= \text{Follow}(E) = \{\$\}$ 
     结果：$\text{Follow}(T) = \{+, \$\}$  
   - 对 $E'$：后缀为空，$\epsilon \in \text{First}(\epsilon)$ ⇒ $\text{Follow}(E') \cup\!= \text{Follow}(E) = \{\$\}$ 
     结果：$\text{Follow}(E') = \{\$\}$

2. **产生式 $E' \to + T E'$**  
   - 对 $T$：后缀 $E'$，$\text{First}(E')-\{\epsilon\} = \{+\}$ → $\text{Follow}(T) \cup\!= \{+\}$（已有） 
     $\epsilon \in \text{First}(E')$ ⇒ $\text{Follow}(T) \cup\!= \text{Follow}(E') = \{\$\}$（已有）  
   - 对 $E'$：后缀为空 ⇒ $\text{Follow}(E') \cup\!= \text{Follow}(E')$（无变化）

3. **产生式 $T \to F T'$**  
   - 对 $F$：后缀 $T'$，$\text{First}(T')-\{\epsilon\} = \{*\}$ → $\text{Follow}(F) = \{*\}$ 
     $\epsilon \in \text{First}(T')$ ⇒ $\text{Follow}(F) \cup\!= \text{Follow}(T) = \{+, \$\}$ 
     结果：$\text{Follow}(F) = \{*, +, \$\}$  
   - 对 $T'$：后缀为空 ⇒ $\text{Follow}(T') \cup\!= \text{Follow}(T) = \{+, \$\}$ 
     结果：$\text{Follow}(T') = \{+, \$\}$

4. **产生式 $T' \to * F T'$**  
   - 对 $F$：后缀 $T'$，$\text{First}(T')-\{\epsilon\} = \{*\}$ → $\text{Follow}(F) \cup\!= \{*\}$（已有） 
     $\epsilon \in \text{First}(T')$ ⇒ $\text{Follow}(F) \cup\!= \text{Follow}(T') = \{+, \$\}$（已有）  
   - 对 $T'$：后缀为空 ⇒ $\text{Follow}(T') \cup\!= \text{Follow}(T')$（无变化）

5. **产生式 $F \to ( E )$**  
   - 对 $E$：后缀 $)$ ，$\text{First}(\text{')'}) = \{)\}$ → $\text{Follow}(E) \cup\!= \{)\}$ 
     结果：$\text{Follow}(E) = \{\$, )\}$

**第一轮结束后的 Follow 集：**
$$
\begin{aligned}
\text{Follow}(E)   &= \{\$, )\} \\
\text{Follow}(E')  &= \{\$\} \\
\text{Follow}(T)   &= \{+, \$\} \\
\text{Follow}(T')  &= \{+, \$\} \\
\text{Follow}(F)   &= \{*, +, \$\}
\end{aligned}
$$



### 第二轮

1. **产生式 $E \to T E'$**  
   - 对 $T$：$\epsilon \in \text{First}(E')$ ⇒ $\text{Follow}(T) \cup\!= \text{Follow}(E) = \{\$, )\}$ 
     结果：$\text{Follow}(T) = \{+, \$, )\}$  
   - 对 $E'$：后缀为空 ⇒ $\text{Follow}(E') \cup\!= \text{Follow}(E) = \{\$, )\}$ 
     结果：$\text{Follow}(E') = \{\$, )\}$

2. **产生式 $E' \to + T E'$**  
   - 对 $T$：$\epsilon \in \text{First}(E')$ ⇒ $\text{Follow}(T) \cup\!= \text{Follow}(E') = \{\$, )\}$（已有） 
     结果：$\text{Follow}(T)$ 不变

3. **产生式 $T \to F T'$**  
   - 对 $F$：$\epsilon \in \text{First}(T')$ ⇒ $\text{Follow}(F) \cup\!= \text{Follow}(T) = \{+, \$, )\}$ 
     结果：$\text{Follow}(F) = \{*, +, \$, )\}$  
   - 对 $T'$：后缀为空 ⇒ $\text{Follow}(T') \cup\!= \text{Follow}(T) = \{+, \$, )\}$ 
     结果：$\text{Follow}(T') = \{+, \$, )\}$

4. **产生式 $T' \to * F T'$**  
   - 对 $F$：$\epsilon \in \text{First}(T')$ ⇒ $\text{Follow}(F) \cup\!= \text{Follow}(T') = \{+, \$, )\}$（已有）  
   - 对 $T'$：后缀为空 ⇒ 无变化

5. **产生式 $F \to ( E )$**  
   - 对 $E$：后缀 $)$ ，已添加过，无变化



### 算法结束



第二轮结束后，所有 Follow 集不再变化。



### 最终 Follow 集

$$
\boxed{
\begin{aligned}
\text{Follow}(E)   &= \{\$, )\} \\
\text{Follow}(E')  &= \{\$, )\} \\
\text{Follow}(T)   &= \{+, \$, )\} \\
\text{Follow}(T')  &= \{+, \$, )\} \\
\text{Follow}(F)   &= \{*, +, \$, )\}
\end{aligned}
}
$$
