# 快捷键与技巧

| 快捷键与技巧                       | 描述                                                         | 应用举例                                |
| ---------------------------------- | ------------------------------------------------------------ | --------------------------------------- |
| Ctrl+L                             | 清屏                                                         |                                         |
| ^C           Ctrl+C                | 强制暂停命令/取消当前行的命令                                | tail -f命令                             |
| ^D           Ctrl+D                | 退出该账户/退出专属页面(如python)但不能退出vi和vim           | 这Linux居然装了python????               |
| ^R  命令关键字         Ctrl+R      | 根据输入的命令匹配内容搜索命令并执行                         |                                         |
| ^R  命令关键字         +键盘左右键 | 根据输入的命令匹配内容搜索命令并根据左右键切换选择符合的命令(类似于枪战游戏的换枪),然后执行 | ^R test.txt查找执行test.txt有关指令     |
| histoy                             | 查看历史命令,最近在最下                                      | history \| grep ch>>>过滤以ch开头的命令 |
| !命令                              | 从最近向前搜索历史命令,找到符合要求的命令并执行              | !ch                                     |
| ^A          Ctrl+A                 | 跳到命令开头                                                 |                                         |
| ^E          Ctrl+E                 | 跳到命令结尾                                                 |                                         |
| Ctrl+键盘←                         | 向左跳一个单词                                               |                                         |
| Ctrl+键盘→                         | 向右跳一个单词                                               |                                         |
