## 特殊路径符

用于方便地回到上一级目录

| 特殊路径符 | 含义       | 使用示例       | 描述                                                 |
| ---------- | ---------- | -------------- | ---------------------------------------------------- |
| .          | 当前目录   | cd ./Desktop   | 加不加无所谓                                         |
| ..         | 上一级目录 | cd ../../games | ..回到home  /..回到usr   (..可单独用,回到上一级目录) |
| ~          | HOME目录   | cd ~/Deaktop   | ~可单独用,表示回到上一级目录                         |
