# ls 命令

## 语法

```Linux
ls [-a][-l][-h] [文件路径]
```

## 参数

不写参数**默认**是当前**工作路径**

指定了路径后并不会进入该路径

## 选项

### -a

all

列出所有文件(夹)(包括隐藏的文件(夹))

#### 隐藏文件(夹)

Linux中隐藏文件(夹)前都会有一个".",例如:  .bila  (乱编的)

应该说:以.开头的文件夹默认都会隐藏起来

### -l

list

以列表的形式纵向显示图片并显示更多的信息(使用者,创建日期,内存大小(byte))

### -h

必须和-l一起使用

以易于阅读的方式返回K,M,G形式的内存大小

### 选项一起使用

以下都可以(顺序随意)

```Linux
ls -l -h
ls -l -a -h
ls -la
ls -hl
```

这种不可以

```Linux
ls -l-h
```
