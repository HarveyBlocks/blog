# wc命令

## 语法

```Linux
wc [-c][-m][-l][-w] 文件路径
```

- -c 统计bytes字节数量
- -m 统计字符数量
- -l (line) 统计行数
- -w (word)统计单词数量
- 文件路径.必填,表示要过滤内容的文件路径,**可作为内容的输入端口**
