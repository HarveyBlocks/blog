# 左偏树

堆的一种

## 定义

-   外节点
    -   存在子节点为空的节点
-   距离
    -   节点到节点之间的最短路径长度, 
    -   在左偏树中, 距离特指当前节点到最近的外节点之间的距离
    -   特别的, 当前节点就是外节点, 距离为1
-   左偏树
    -   左孩子的距离总是大于右孩子的距离
-   左偏树的距离
    -   左偏树根节点的距离作为该树的距离

## 性质

-   任意节点，左儿子的距离大于右儿子的距离
-   任意节点，其距离等于它的右儿子的距离加一
-   n个节点的左偏树，其根节点的距离不超过logN
-   距离为d的左偏树，其节点数不少于2^k+1^−1

## 合并

堆根X, Y

1.  找出较小优先级的根, 此处X为例
2.  在X的右子树中找到第一个优先级比Y大的节点K, 合并K和Y, X抛弃K节点
3.  K和Y合并之后的树, 会有一个新的根, 将本根填补X抛弃K节点后的空缺
4.  在合并过程中, 左孩子的距离小于右孩子的距离，则交换左右孩子

## 删除根

合并根的左右孩子

## 删除节点

1.  左右儿子合并
2.  自底向上更新距离
3.  不满足左偏性质时交换左右儿子
4.  当距离满足, 无需更新时结束递归
