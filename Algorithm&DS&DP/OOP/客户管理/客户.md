## 客户关系管理

## 用况：买家 VIP 与折扣优惠

| Tittle   | Description                                                  |
| -------- | ------------------------------------------------------------ |
| 用况名   | 买家 VIP 与折扣优惠管理                                      |
| 描述     | 系统根据客户消费总额自动评定 VIP 等级，并配置对应折扣策略。商家可设置不同等级客户的专属权益与优惠券发放规则。 |
| 参与者   | `Seller`, `SystemAdmin`                                      |
| 包含     | `查看客户 VIP 等级`, `设置折扣规则`, `发放优惠券`, `查看优惠使用情况` |
| 扩展     | 若客户达到升级门槛，系统自动升级其 VIP 等级并发送通知。      |
| 泛化     | `普通客户` → `VIP 客户`（基于消费金额）                      |
| 前置条件 | 客户已完成至少一笔订单；商家已配置 VIP 等级规则与折扣策略。  |
| 细节     | 1. 系统每日定时计算客户累计消费金额。<br>2. 根据预设规则（如：满 500 元为银卡，满 2000 元为金卡）自动更新客户 VIP 等级。<br>3. 商家可在后台设置各等级对应的折扣比例（如金卡享 9 折）。<br>4. 支持批量向特定等级客户发放优惠券。<br>5. 优惠券使用时自动校验客户等级与有效期。 |
| 后置条件 | 客户 VIP 等级更新成功；折扣规则生效；优惠券已发放并记录状态。 |
| 例外     | - 客户消费金额未达标 → 不予升级。<br>- 优惠券已过期 → 提示“该优惠券已失效”。<br>- 同一客户重复领取 → 阻止重复发放。 |
| 注释     | VIP 等级变更需通知客户；折扣策略支持按商品类别单独配置。     |





- **查看客户资料**  
  员工可在系统中查看客户的姓名、联系方式、注册时间等基本信息，用于快速识别客户身份。该功能仅展示非敏感信息，支持在客户详情页中调用。
- **计算客单价**  
  系统根据客户历史订单的总金额与订单数量，自动计算其平均客单价（公式：`总消费 / 订单数`），并存储至客户档案，供商家评估客户价值。
- **添加标签**  
  员工可为客户提供自定义标签（如“高价值客户”、“常客”），便于后续分类管理与精准营销。标签支持从预设池选择或手动输入，仅限当前商家可见。
- **添加备注**  
  员工可在客户档案中添加文本备注，记录沟通重点或客户偏好，辅助个性化服务。备注内容可追加，不可删除，支持多行输入。



## 用况：查询交易历史

| Tittle   | Description                                                  |
| -------- | ------------------------------------------------------------ |
| 用况名   | 查询交易历史                                                 |
| 描述     | 员工可查看指定客户的全部订单记录，包括商品名称、数量、金额、下单时间等，用于分析购买行为和提供售后服务。 |
| 参与者   | `Seller`, `CustomerService`                                  |
| 包含     | 无                                                           |
| 扩展     | 支持按时间段、商品类别筛选订单；点击订单可查看详情。         |
| 泛化     | 无                                                           |
| 前置条件 | 客户已完成至少一笔订单；用户具备查看订单权限。               |
| 细节     | 1. 在客户详情页点击“交易历史”标签。<br>2. 系统加载该客户的所有订单。<br>3. 展示订单列表，支持分页和搜索。 |
| 后置条件 | 订单列表成功加载并展示。                                     |
| 例外     | - 客户无订单 → 显示“暂无交易记录”。<br>- 数据库异常 → 提示“加载失败”。 |
| 注释     | 支持导出为 CSV 格式供后续分析使用。                          |
