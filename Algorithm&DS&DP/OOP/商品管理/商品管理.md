# 羽毛球商品管理用况分析

## 用况1：添加新商品

**用况简介**：此用况是商品管理的起点，通过规范化的商品信息录入流程，确保商品数据的完整性和准确性。对于羽毛球专卖店，重点在于准确记录球拍参数、穿线服务选项等专业信息。

| 属性 | 描述 |
|------|------|
| **用况名** | 添加新商品 |
| **描述** | 卖家录入新到商品的基本信息、规格参数、价格及库存数据，特别关注羽毛球专业属性的记录。 |
| **参与者** | 卖家（具有商品管理权限的店员或店长） |
| **包含** | 无 |
| **扩展** | 无 |
| **泛化** | 无 |
| **前置条件** | 1. 卖家已成功登录系统<br>2. 卖家具有商品管理权限<br>3. 商品实物已到店并完成验收 |
| **细节** | 1. **进入商品添加页面**：卖家在商品管理模块点击"添加新商品"<br>2. **填写商品基本信息**：<br>   - **基础信息**：商品名称（如"尤尼克斯天斧100ZZ"）、品牌、分类（球拍、球鞋、服装等）<br>   - **规格参数**：重量（U表示）、平衡点、长度、材质、穿线方式等专业属性<br>   - **价格信息**：进货价、销售价、会员价<br>   - **库存信息**：初始库存数量、安全库存阈值<br>3. **设置服务选项**：<br>   - **穿线服务**：是否提供穿线服务、可穿线磅数范围、可选线材类型<br>   - **附加服务**：是否提供手胶更换、免费穿线等<br>4. **上传商品图片**：支持多角度展示，特别是球拍细节<br>5. **保存商品信息**：点击"保存"，系统验证数据完整性 |
| **后置条件** | 1. 新商品信息成功录入系统<br>2. 商品状态设置为"上架"或"待上架"<br>3. 系统记录添加人和添加时间 |
| **例外** | 1. 必填信息不完整，系统阻止保存并提示<br>2. 商品编码重复，系统提示修改<br>3. 价格格式错误，系统校验不通过 |
| **注释** | 羽毛球专业参数必须准确记录，这是专业店铺的核心竞争力 |

## 用况2：管理商品库存

**用况简介**：此用况负责跟踪和维护商品库存状态，确保库存数据的实时准确性。重点在于及时更新库存变动，设置合理的库存预警机制。

| 属性 | 描述 |
|------|------|
| **用况名** | 管理商品库存 |
| **描述** | 卖家通过多种方式更新商品库存数量，系统自动跟踪库存变动并触发库存预警。 |
| **参与者** | 卖家（具有库存管理权限的店员） |
| **包含** | 无 |
| **扩展** | 无 |
| **泛化** | 无 |
| **前置条件** | 1. 卖家已成功登录系统<br>2. 系统中存在需要库存管理的商品<br>3. 卖家具有库存管理权限 |
| **细节** | 1. **查看库存列表**：系统展示所有商品当前库存状态，低库存商品高亮显示<br>2. **库存调整方式**：<br>   - **采购入库**：录入新采购商品的数量、进货价<br>   - **盘点调整**：定期盘点后，调整库存差异<br>   - **损毁登记**：登记损坏、过期等不可售商品<br>3. **设置库存预警**：为每个商品设置最低库存阈值，系统自动监控<br>4. **库存变动记录**：系统记录每次库存变动的类型、数量、操作人、时间<br>5. **生成采购建议**：基于销售数据和库存水平，系统生成采购建议清单 |
| **后置条件** | 1. 商品库存数量准确更新<br>2. 库存变动记录完整保存<br>3. 触发库存预警时，系统生成待处理任务 |
| **例外** | 1. 库存调整后数量为负，系统阻止操作<br>2. 无权限操作，系统拒绝执行<br>3. 同一商品同时操作，系统提示冲突 |
| **注释** | 重点商品（如热销球拍、羽毛球）需要更频繁的库存检查和更低的预警阈值 |

## 用况3：更新商品信息

**用况简介**：此用况负责维护商品信息的准确性和时效性，特别是价格调整和商品状态变更。确保前台展示与实际情况一致。

| 属性 | 描述 |
|------|------|
| **用况名** | 更新商品信息 |
| **描述** | 卖家修改已存在商品的信息，包括价格调整、参数修正、状态变更等操作。 |
| **参与者** | 卖家（具有商品编辑权限的店员） |
| **包含** | 无 |
| **扩展** | 无 |
| **泛化** | 无 |
| **前置条件** | 1. 卖家已成功登录系统<br>2. 目标商品已存在于系统中<br>3. 卖家具有商品编辑权限 |
| **细节** | 1. **查找目标商品**：通过商品名称、编码或分类筛选定位商品<br>2. **信息修改操作**：<br>   - **价格调整**：修改销售价、会员价，可选择立即生效或指定时间生效<br>   - **参数修正**：更新商品规格、描述等基本信息<br>   - **状态变更**：上架/下架商品，设置热销、推荐等标签<br>   - **服务更新**：调整穿线服务选项、可用线材类型等<br>3. **修改记录**：系统记录每次修改的字段、旧值、新值、修改人和时间<br>4. **批量操作**：支持同类商品批量调价、批量上下架<br>5. **确认修改**：点击"保存"，系统验证数据合法性 |
| **后置条件** | 1. 商品信息成功更新<br>2. 修改记录完整保存<br>3. 前台展示同步更新 |
| **例外** | 1. 关键信息缺失，系统阻止保存<br>2. 价格不符合业务规则（如售价低于进价），系统提示确认<br>3. 商品已被订单引用，重要修改需要额外确认 |
| **注释** | 价格变动需要谨慎处理，特别是调价时考虑已存在订单的处理 |

## 用况4：管理商品进销价格

**用况简介**：此用况专门负责商品进货价和销售价的设置与调整，确保价格数据的准确性和业务合理性。重点在于建立价格审批机制，防止价格设置错误导致的经营风险。

| 属性 | 描述 |
|------|------|
| **用况名** | 管理商品进销价格 |
| **描述** | 卖家设置或调整商品的进货价格和销售价格，系统进行价格合理性校验，重要价格变动需要审批流程。 |
| **参与者** | 卖家（具有价格管理权限的店员）、店长（价格审批者） |
| **包含** | 无 |
| **扩展** | 无 |
| **泛化** | 无 |
| **前置条件** | 1. 操作人员已成功登录系统<br>2. 目标商品已存在于系统中<br>3. 操作人员具有相应的价格管理权限 |
| **细节** | 1. **进入价格管理界面**：在商品管理模块选择"价格管理"<br>2. **价格设置操作**：<br>   - **录入进货价**：根据供应商报价录入最新进货价格，支持批量导入<br>   - **设置销售价**：基于进货价和利润率自动计算建议售价，可手动调整<br>   - **价格层级管理**：设置零售价、会员价、批发价等多级价格体系<br>3. **价格审批流程**：<br>   - **普通调整**：小幅度调价（如±10%以内）可直接生效<br>   - **重大调整**：大幅度调价需提交店长审批，审批通过后生效<br>   - **紧急调价**：特殊情况可申请紧急调价，需说明理由<br>4. **价格历史跟踪**：系统记录每次价格变动的详细信息<br>5. **价格生效管理**：支持立即生效或指定未来时间生效 |
| **后置条件** | 1. 商品价格信息成功更新<br>2. 价格变动记录完整保存<br>3. 相关订单和库存计算同步更新 |
| **例外** | 1. 销售价低于进货价，系统阻止操作并警告<br>2. 权限不足，系统拒绝价格修改请求<br>3. 审批流程未完成，价格变更暂不生效<br>4. 价格格式错误，系统校验不通过 |
| **注释** | 重点商品（如高端球拍）的价格变动需要更严格的审批流程 |

## 价格管理业务规则

### 进货价管理规则
1. **最新进货价优先**：系统自动采用最近一次的有效进货价
2. **供应商对比**：同一商品多个供应商时，系统显示各供应商价格对比
3. **进货价保密**：进货价仅对授权人员可见，前台不展示

### 销售价定价策略
1. **利润率控制**：根据不同商品类别设置最低利润率
    - 球拍类：最低利润率20%
    - 羽毛球类：最低利润率15%
    - 配件类：最低利润率30%
2. **市场竞争调整**：参考市场价格进行适当调整
3. **促销价格管理**：临时促销价格设置有效期，到期自动恢复

### 价格审批权限
| 价格调整幅度 | 审批要求 | 生效时间 |
|-------------|---------|---------|
| ±10%以内 | 店员直接修改 | 立即生效 |
| ±10% - ±20% | 店长审批 | 审批通过后生效 |
| ±20%以上 | 店长+区域经理审批 | 双重审批后生效 |

## 价格监控与预警

### 自动监控机制
1. **负毛利预警**：当销售价接近或低于进货价时自动预警
2. **价格异常检测**：与历史价格和市场价格对比，发现异常波动
3. **竞争对手价格跟踪**：记录主要竞争对手价格，供定价参考



### 实施方案特点
1. **专业性强**：商品参数设计符合羽毛球专业标准，满足专业玩家需求
2. **操作便捷**：提供批量操作、模板导入等便捷功能，提高管理效率
3. **数据完整**：完整的操作日志和修改记录，确保数据可追溯
4. **预警及时**：智能库存预警机制，避免缺货或积压情况

**实施要点**：价格管理涉及店铺核心利益，必须建立严格的操作权限和审批流程，同时保证价格数据的准确性和及时性。
