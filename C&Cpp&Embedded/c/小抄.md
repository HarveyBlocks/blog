##### 指针

```
const char *ptr;
ptr指向的内容可以变
不能通过ptr改*ptr
ptr指向str，而str不是const,可以直接通过str变量来修改str的值

char const *ptr;
和const char *等价

char * const ptr;
ptr是常量
ptr指向的对象可以变

const char * const ptr;
ptr 是常量, ptr指向的对象也是常量
```

```c
int a = 2;
int *ip = &a; 
const int *cip = &a; // 不能通过cip改变a的值, 可以通过cip改变cip指向的对象
int const *icp = &a; // 不能通过icp改变a的值, 可以通过icp改变icp指向的对象
int *const ipc = &a; // 可以通过ipc改变a的值, 不能通过ipc改变ipc指向的对象
```

##### 位域

1. 占用内存大小, 总是类型内占用空间最大的数据类型的整数倍, 但不会无限增加, 最多是8的倍数
2. 没有数据的类型占用1 byte的空间
3. 从上往下, 类型一样的, 且放在一起的分组
     同一组内:
     1. 依据这一组的类型的内存空间开辟一个类型单位的大小
     2. 然后以后面指定的数字分占同一个类型单位的空间
     3. sc
     4. 如果有一个数据像一座桥一样跨在两个类型单位的空间上, 则这个数据占用新的类型单位的空间
     5. 此时, 前一个空间末尾的几个位置被闲置, 不被使用
