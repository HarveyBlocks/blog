#   编译

这一步会:

1.  把C语言的高级语言编译成汇编语言
2.  找出语法错误(编译错误)

## 动态编译

-   使用动态库文件

```Linux
gcc hello.c -o hello
```

## 静态编译

-   使用静态库文件

```.0
gcc static hello.c -o
hello
```

## 区别

使用的库文件格式不一样

-   静态编译要把静态库文件打包编译到可执行文件中
-   动态编译不会把动态库打包编译到可执行文件中,它只是编译链接关系

-> 动态编译之后的程序运行时还要加载动态库

-   动态编译体积小,速度慢,不能在没有库的机子上运行
-   静态编译体积大,速度快,,可以在没有库的机子上运行

### 各自的用处一目了然

-   动态编译做测试,体积小,可以存放多个版本,而且本机上有库
-   静态编译做发布,体积大?无所谓,速度快,体验佳,别人的机子上不一定有库,有也不一定能连接上
