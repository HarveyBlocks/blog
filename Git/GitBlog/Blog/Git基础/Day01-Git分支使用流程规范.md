# 开发中分支使用原则与流程

- master分支
  - 生产分支
  - 唯一可以上线(发布)的分支
  - 稳定的
  - 主分支
  - 中小规模项目作为线上运行的应用对应的分支
- develop分支
  - 开发分支
  - 从master分支创建
  - 作为开发部门的主要开发分支
  - feature分支需要合并给develop分支
  - 不能删
  - 最终需要合并到master分支
- feature分支
  - 从develop分支创建
  - 可以操作的分支
  - 多次更改
  - 即用即删
  - 合并到develop分支
- hotfix分支
  - 修bug的分支
  - 从master产生
  - 合并到develop和master分支
